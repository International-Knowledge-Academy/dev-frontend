## Featured Project

### 🎓 IKA — International Knowledge Academy Platform

> Full-stack web platform for a global professional training and development academy

A production platform serving three distinct audiences — admins, account managers, and the public — built with a focus on performance, usability, and maintainability.

**What I built:**
- **Public website** — programs catalog, category browser, multi-step registration flow, trainer application, certificate verification
- **Admin dashboard** — full CRUD for programs, users, trainers, locations, categories, fields, registrations, payments, services, partnerships, certificates
- **Account Manager panel** — scoped access for managing registrations, programs, and payments
- **E2E test suite** — 33 Playwright spec files covering all modules across all three portals

**Stack:** React · TypeScript · Tailwind CSS · Django REST Framework · Vercel · Playwright
